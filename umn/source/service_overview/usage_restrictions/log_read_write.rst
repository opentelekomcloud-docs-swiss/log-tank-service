Log Read/Write
==============

This section describes the restrictions on LTS log read/write.

.. table:: **Table 1** Log read/write constraints

   +-------------------------+-----------------------------------------+------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------+
   | Category                | Item                                    | Description                                                                                                                  | Remarks                                                                                                                                                 |
   +=========================+=========================================+==============================================================================================================================+=========================================================================================================================================================+
   | A complete LTS          | Steady log rate                         | Steady log rate = Volume of new logs per day/24 hours/3,600 seconds                                                          | If your steady log rate exceeds the corresponding standard throughput baseline for a long time, logs may be stacked and the disk space may become full. |
   |                         |                                         |                                                                                                                              |                                                                                                                                                         |
   |                         |                                         | The maximum steady rate is 1,000 MB/s.                                                                                       |                                                                                                                                                         |
   +-------------------------+-----------------------------------------+------------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------+
   |                         | Log query traffic                       | Up to 10 MB of logs are returned in a single API query in a complete LTS.                                                    | N/A                                                                                                                                                     |

   |                         | Medium specifications (management zone) | Throughput baseline: 6 MB/s                                                                                                  | N/A                                                                                                                                                     |
