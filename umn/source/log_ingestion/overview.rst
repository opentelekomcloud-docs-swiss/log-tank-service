Overview
========

LTS enables you to ingest logs from cloud services in real time using means such as APIs. Ingested logs are displayed on the LTS console in an intuitive and orderly manner. You can query logs that you need quickly and with ease.

-  :ref:`Collecting Logs from Cloud Services <lts_04_0105>`: LTS supports log ingestion from cloud services. Click a cloud service to configure access to it.
-  :ref:`Collecting Logs Using APIs <lts_04_0215>`: You can use LTS APIs to report logs to LTS.
-  :ref:`Other Ingestion Modes <lts_04_1121>`: Cross-account ingestion and self-built Kubernetes ingestion are supported.
